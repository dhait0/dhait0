## Featured Projects

### WebKitsunova Proyecto
A unified full‑stack application built with Next.js 16 (App Router), React 19, Prisma, Supabase, Tailwind CSS, and Vitest. Features server components, server actions, HTTP‑only cookie auth, and Docker‑based local development.
- **Tech Stack**: Next.js, React, TypeScript, Prisma, Supabase, Tailwind, Docker, Vitest
- **Source**: https://github.com/dhait0/webkitsunova-proyecto

### Nexus n8n Workflow Kit
A bilingual collection of importable n8n workflows for enterprise automation, incident routing, vendor risk intake, AI governance, and Microsoft Graph lifecycle sync. Includes credential‑safe placeholders, webhook and HTTP request nodes, and a local validation script.
- **Tech Stack**: n8n, JSON, Docker (for validation)
- **Source**: https://github.com/dhait0/nexus-n8n-workflow-kit

### Forge CI Deploy Pipeline
A bilingual Jenkins, Docker, and Linux demo for building, testing, packaging, smoke testing, and rolling back a mock TypeScript service. Shows declarative Jenkins pipelines, multi‑stage Docker builds, Compose smoke tests, and Linux preflight scripts.
- **Tech Stack**: Node.js, TypeScript, Jenkins, Docker, Linux
- **Source**: https://github.com/dhait0/forge-ci-deploy-pipeline
